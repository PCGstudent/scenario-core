# AI-assisted development

I used ChatGPT for scaffolding and implementation, and Claude Code for review rounds. Both read `AGENTS.md`, a repo-level context file in this repository holding the objective, the module layout, and a numbered list of statistical invariants — "never concatenate independent synthetic paths before computing ACF", "VaR/ES use loss `L = -return` and are positive loss magnitudes", "a FAIL is evidence, not a defect to hide". Numbering is what made them enforceable: an assistant can be held to invariant 5 in a way it cannot be held to a general instruction about rigour, and every mistake found since has been written back into that list as a new one.

Two flows carried the work. A **spec-driven scaffolding loop** — requirement, then explicit interface and acceptance criterion, then AI draft, then manual simplification — which kept the repository small and talked me out of an attractive but unjustified neural generator. And an **adversarial audit pass**, in which an assistant given no prior context was told to attack the central argument and reproduce every reported number from the data, rather than to review the code.

AI drafted the initial threshold table and implemented both candidate models. I did not delegate the decision procedure: thresholds frozen before the comparison, the risk-measure sign convention fixed, and no automatic score allowed to select a model.

The mistake worth reporting was in AI-written *validation* rather than model code, and it arrived while fixing an earlier one. Correcting a sample-size flaw meant re-estimating the squared-return ACF inside 252-day blocks, which shrinks the historical target roughly threefold — so the inherited absolute tolerance no longer bound anything. A negative control caught it: feed the gate an iid bootstrap of the real returns, which has the exact historical marginal and no volatility clustering whatsoever. It scored 0.0498 against a 0.05 threshold and passed. The tolerance is now a fraction of the scale under the estimator in use, a regression test asserts that rejection, and the correction makes my own submitted model fail that gate. The general lesson, now an invariant: a gate that nothing can fail is not a gate.
