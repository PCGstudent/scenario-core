# AI-assisted development

I used ChatGPT to scaffold and implement, and Claude Code for a repo-level audit round near the end. I treated both as fast collaborators rather than authorities: the assessment requirements were first translated into explicit acceptance criteria, repository invariants and a small module structure in `AGENTS.md`, which is the context file both tools read before editing. Numbering the statistical invariants turned out to matter more than any prompt wording — an assistant can be held to "invariant 5: never concatenate independent paths before computing ACF" in a way it cannot be held to a vague instruction about rigour.

Three flows did the work. A **spec-driven scaffolding loop**: requirement → explicit interface and acceptance criterion → AI draft → manual simplification, which kept the repository small and avoided an attractive but unjustified neural generator. A **validation-driven challenger loop**: run the baseline, inspect which declared gates fail, propose one targeted refinement, compare under identical thresholds rather than moving the goalposts. And an **adversarial audit pass**, where the assistant had to reproduce every number in the report from the data before any claim about it could stand.

I did not delegate the risk-measure sign convention, the threshold table, what counts as a failure, or the model selection. AI could propose candidates and comparison logic; the rationale had to stay inspectable from the reported evidence.

Three AI mistakes were caught, each by a different mechanism. The first comparison logic declared the model with more passed gates the winner; reviewing failure severity showed the challenger passing more gates while missing kurtosis far worse, so I rejected the automatic label. A later review caught `alpha + gamma/2 + beta` used as GJR persistence, which is only the symmetric-innovation shortcut — the code now computes the skew-t partial second moment explicitly. The most consequential came from the audit pass: the validation compared full-sample historical statistics against pooled synthetic ones, so two gates were failing on estimator sample size rather than model error. The tell was that the ACF failure sat at a near-constant level across seeds while everything else moved. Fixing the estimator rather than the thresholds changed what the report claims the model gets wrong.
