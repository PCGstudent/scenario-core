# AI-assisted development

I used ChatGPT to scaffold and implement, and Claude Code for review rounds near the end. Both read `AGENTS.md`, a repo-level context file holding the objective, the module layout and a numbered list of statistical invariants. The numbering matters: an assistant can be held to "invariant 5: never concatenate independent paths before computing ACF" in a way it cannot be held to a general instruction about rigour, and the list is where each caught mistake is written down so it cannot recur.

Three flows did the work. A **spec-driven scaffolding loop**: requirement → interface and acceptance criterion → AI draft → manual simplification, which kept the repository small and avoided an attractive but unjustified neural generator. A **validation-driven challenger loop**: run the baseline, inspect which gates fail, make one targeted refinement, compare under identical tolerances rather than moving the goalposts. And an **adversarial audit pass**, where an assistant with no prior context had to reproduce every reported number and attack the central argument.

AI proposed the initial threshold table and both candidate models. I did not delegate the decision procedure: thresholds were frozen before the comparison, the risk-measure sign convention stayed fixed, and no automatic score selected the model. That rule earned its keep when an early comparison declared the model with more passed gates the winner, while review of failure severity showed it missing kurtosis far worse.

Two later mistakes were more instructive, because both were in AI-written *validation* rather than model code. First, the suite compared full-sample historical statistics against pooled synthetic ones, so two gates were failing on estimator sample size rather than model error; the tell was the ACF failure sitting at a near-constant level across seeds. Second — caught only by the adversarial pass, and only because it was told to attack rather than review — fixing that introduced a subtler fault. Re-estimating the ACF inside 252-day blocks shrinks the historical target roughly threefold, so carrying the old absolute tolerance across meant the gate could no longer fail: an iid bootstrap of the real returns passed it. The fix was to express the tolerance as a fraction of the scale under the estimator in use, plus a regression test that feeds the gate a generator with no volatility clustering and asserts rejection. The lesson became an invariant: a gate that nothing can fail is not a gate.
